Send Text Settings

1. Target & Submission

Enter the tab number you want to target (e.g., 1 for the first tab, 2 for the second).

2. Hotkey Shortcut

You can send the selected text using a keyboard shortcut (default: Alt+D).

You can send the text or image under your mouse cursor using a keyboard shortcut (default: Ctrl+9).

To customize this shortcut, go to chrome://extensions/shortcuts.

3. Icon Position Anchor

Choose the corner of the text selection to use as a base position.

4. Position Offset

Use the sliders to adjust the icon's position relative to the anchor point.
